VERSION = 1,

/*
    Auto All - server overrides for each automation.

    THESE ARE TRI-STATE INTEGERS, NOT BOOLEANS, AND THAT IS DELIBERATE.

        -1  the server does not care - the player's own setting decides
         0  force off for everyone on this server
         1  force on for everyone on this server

    They were booleans at first, and that was a real bug. A boolean cannot
    tell "the server has not expressed an opinion" apart from "the server
    turned it off", so on a save that predates these options the value
    read back as false and silently switched modules off for players who
    had never touched them. It was reported as "the options just
    disappear" and as "works in a new world, not in my old save", and a
    client log showed six modules off while ModOptions.ini said all ten
    were on.

    -1 is the default, so a server that never opens this page changes
    nothing, and a value that is neither 0 nor 1 is ignored rather than
    obeyed. See AA.enabled in AutoAll_Core.lua, which also writes a line
    to console.txt whenever one of these actually vetoes something.
*/
