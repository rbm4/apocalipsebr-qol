ERS FRAMEWORK - OPCION 2
========================

Esta opcion documenta el contrato de API para mods externos.
ERS Core ya expone registro de productores y baterias por API.

RUTA CORE
---------
Shared:
- media/lua/shared/EnergyRouting/Registry.lua
- media/lua/shared/EnergyRouting/API.lua
- media/lua/shared/EnergyRouting/ProducerBase.lua

API PUBLICA
-----------
Requerir:
  require "EnergyRouting/API"

Registrar productor:
  EnergyRouting.API.RegisterProducer(def)

Campos recomendados de def:
- id (string, requerido, unico)
- displayName (string, opcional)
- category (string: "solar" | "wind" | "hydro" | "other")
- sortOrder (numero, opcional)
- controllerListKey (string, opcional si usas CollectObjects)
- idPrefix (string, opcional si usas CollectObjects)
- IsObject(obj) -> bool (funcion, opcional si usas CollectObjects)
- CollectObjects(self, controller, runtimeContext) -> {obj...} (opcional)
- CalculateOutput(obj, weatherSnapshot, networkContext, runtimeContext, def) -> watts (requerido)
- OnFailure(obj, networkContext) (opcional)

Registrar bateria:
  EnergyRouting.API.RegisterBattery(def)

Campos recomendados de bateria:
- id (string, requerido, unico)
- displayName (string, opcional)
- sortOrder (numero, opcional)
- capacity (numero, opcional)
- GetCapacity(obj, def) -> numero (opcional, prioridad sobre capacity)

PROCESO DE FALLOS
-----------------
Para ejecutar fallos definidos por productor:
  EnergyRouting.ProcessFailure(producerObject, networkContext)

RUNTIME CONTEXT (CalculateOutput)
---------------------------------
weatherSnapshot:
- label
- multiplier (si aplica)

networkContext:
- id (network id)
- controller (tabla del controlador)

runtimeContext:
- solarEfficiency
- solarNetworkBonus
- solarBonusPercent
- windWeather
- windNetworkBonus
- windBonusPercent
- weatherSnapshot
- network

NOTAS DE COMPATIBILIDAD
-----------------------
- ERS mantiene productores core registrados:
  - core_solar_panel
  - core_wind_turbine
  - core_hydro_turbine
- ERS mantiene baterias core registradas:
  - core_solar_battery
  - core_wind_battery
- Produccion de modulos externos se acumula en:
  - otherProduction
  - otherCount

EJEMPLO MINIMO (PRODUCTOR EXTERNO)
----------------------------------
require "EnergyRouting/API"

EnergyRouting.API.RegisterProducer({
    id = "mini_reactor_mk1",
    displayName = "Mini Reactor",
    category = "other",
    sortOrder = 200,
    CollectObjects = function(self, controller, runtimeContext)
        -- Retornar objetos del mundo que pertenecen a este productor
        return {}
    end,
    CalculateOutput = function(obj, weather, network, runtimeContext, def)
        -- Retornar watts (numero >= 0)
        return 2500
    end,
    OnFailure = function(obj, network)
        -- Evento opcional de fallo
    end,
})
